# 🗺️ Roadmap de HanziFlow

## ✅ MVP Completado
- [x] Input de texto libre (oraciones/párrafos)
- [x] Grid de caracteres interactivo
- [x] Visualización de trazos con Hanzi Writer
- [x] Modo práctica de escritura (quiz)
- [x] Navegación con teclado entre caracteres (← → / A D)
- [x] Navegación por trazos individuales (↓ S: +trazo / ↑ W: −trazo)
- [x] Play/Stop con reanudación desde posición actual (SPACE)
- [x] Reproducir desde inicio (R)
- [x] Continuar reproducción desde trazo actual (SPACE tras stepping)
- [x] Switch rápido de modo: H (ver trazos) / T (practicar)
- [x] Control de velocidad en tiempo real (1-9) con efecto inmediato
- [x] Velocidad de stepping siempre rápida (independiente de 1-9)
- [x] Ejemplos rápidos integrados
- [x] Diseño responsive
